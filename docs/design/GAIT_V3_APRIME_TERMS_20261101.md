## 1. 적용 범위의 정의

| 용어 | 정의 (코드) |
|---|---|
| 계단 | 계단 6종 타일: `pyramid_stairs`, `_inv`, `_wide`, `_inv_wide`, `_nose`, `_inv_nose` (`STAIR_FAMILIES`). `off_shaped=True`인 항목은 여기서 0 (`shaped_mask`) |
| 경사 | `hf_pyramid_slope`, `hf_pyramid_slope_inv`. G3에서는 계단과 함께 껐고 G4에서 다시 켬 (`GAIT_SHAPE_SLOPES=0`이면 G3처럼 끔) |
| 갭 | `platform_gap` 타일 (`boarding_family_mask`). "슬롯 근처" = 어느 발이든 슬롯에서 0.5 m 안 (`_GapSlots.foot_over_slot`) |
| 후진 갭 | 갭 타일이면서 이동 방향이 후진(명령 vx ≤ −0.1, 명령이 없으면 몸통 속도) (`back_gap_mask`). `off_back_gap=True`인 항목은 여기서 0 |
| ramp | `gait_weight_ramp` 커리큘럼 항목. 배율 κ = κ_min + (1 − κ_min)·min(1, env step / 20,000). κ_min 0.2, R8은 0.34, R18은 0.625. 20,000 env step = 200 update × 100 step |
