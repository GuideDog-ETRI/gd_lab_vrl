# 설계서: 보행 품질 v3 (평지 자세 유지 · 조용한 착지 · 갭 건너기 다리 추종)

2026-11-01 · 작성 중 (초안 1) · 브랜치 `feat/gast-narrow-turn` · 관련: `WORKORDER_STAGE_B_V25_20261031.md`(B 보류), `GAST_NARROW_V25_DESIGN.md`

**배경 (사용자, 11-01 새벽):** 한강 A 모델 1944와 6566의 MuJoCo 영상에서 (1) 갭을 넘을 때 뒤따르는 두 발이 급하게 "쿵쿵"
따라오고, (2) 후진 갭에서는 앞서는 뒷발이 버티다가 몸통이 넘어간 뒤에야 급히 따라가며, (3) 평지 보행에서도 뒷발이 끌리듯
따라오고 발소리가 클 것 같고, (4) 평지에서 앞머리(몸통 앞쪽)가 들린다. **한강 B 제출은 보류**하고 평지 습성부터 다시 설계한다.

---

## 1. 측정으로 확인한 것

도구: `tools/rl_replay/record_rollout.py`(Isaac, 과제 `Gd-GastRayIrV21Gap50BackV2`, 32 env × 8 s, 100 Hz 보상 항목별 기록)과
MuJoCo 갭 전용 코스(`gap_pit65`, `gap_back_pit65`, 외력 없음). 분석 스크립트는 이 세션의 scratchpad `gait_analysis.py`
(기록 파일 `logs/rl_replay/hind_{3906,6566,1944}_{fwd05,back03}.json`, MuJoCo 기록 `gd_rbq10_deploy_vrl/records/gap_1944_vs_6566_20261101/`).

### 1.1 머리 들림 (nose-up, 몸통 앞쪽이 위로 드는 피치)

| 상황 | 3906 | 6566 | 1944 |
|---|---|---|---|
| Isaac 갭 구간 전진 p90 / 최대 | 12.6 / 17.4° | 12.9 / 16.5° | 14.2 / 16.6° |
| Isaac 평지 전진 평균 / 최대 | 1.3 / 4.2° | 1.4 / 4.9° | **3.3 / 11.4°** |
| Isaac 평지 후진 평균 | 1.8° | 1.1° | **3.1°** |
| MuJoCo 평지 전진 평균 / 최대 | 1.4 / 5.8° | 6.3 / 11.5° | **8.4 / 18.4°** |
| MuJoCo 평지 후진 평균 / 최대 | 0.9 / 4.5° | 2.5 / 8.2° | **7.6 / 35.7°**(1회 휘청) |

- 갭 앞에서 앞을 드는 자세는 **3906부터** 있다(뒷다리로 밀고 건너는 동작). 바뀐 것은 그 자세가 **평지로 번진 정도**이며,
  갭 학습이 길수록(6566 → 1944) 더 번진다.
- MuJoCo에서 1944 평지 전진을 조건별로 돌린 결과: 적재 0 kg 8.8°, 관측 노이즈·자세 오차 끔 9.5°, 둘 다 끔 8.2°,
  지형 입력을 정답 지도(GT)로 교체 10.9°. **적재·노이즈·자세 오차·센서 지도 품질은 원인이 아니다.** 남은 후보는
  MuJoCo 물리/액추에이터 차이와 IR 채널 분포 차이이며, 1944가 3906보다 이 차이에 훨씬 민감하다
  ("조금 다른 입력이면 갭 자세로 간다"). 실기 센서는 MuJoCo 쪽에 가까우므로 실기에서도 같은 위험이 있다.

### 1.3 갭 건너기 (Isaac, 슬롯이 시야 안에 있는 구간)

| 항목 | 3906 | 6566 | 1944 |
|---|---|---|---|
| 전진: 뒤따르는 발이 이륙 순간 엉덩이보다 **뒤처진 거리** 평균 / p90 | 21 / 31 cm | 24 / 33 cm | 24 / 34 cm |
| 전진: 뒷발 스윙 최고 속도 p90 / 착지 속도 p90 | 3.5 / 1.5 m/s | 3.7 / 1.4 | 3.2 / 1.3 |
| 전진: 앞발 스윙 최고 속도 p90 / 착지 속도 p90 | 4.5 / 1.8 m/s | 4.3 / 2.0 | 4.2 / 1.7 |
| 후진: 앞서는 뒷발이 이륙 전 **버틴 시간** p90 | 0.71 s | 0.92 s | 0.78 s |
| 후진: 뒤따르는 앞발 뒤처진 거리 평균 / p90 | 3 / 11 cm | **10 / 18 cm** | 1 / 12 cm |
| 후진: 뒤따르는 앞발 착지 속도 p90 | 1.3 m/s | **1.8 m/s** | 1.5 m/s |

- 전진 갭: 뒤따르는 발이 엉덩이에서 30 cm 이상 뒤처질 때까지 디디고 있다가(과신전) 3~4.5 m/s로 날아와 1.3~2 m/s로
  떨어진다. **세 모델 모두 같다.** 사용자가 영상에서 본 "급하게 쿵쿵 따라오는 발"이 이것이다.
- 후진 갭: 앞서는 뒷발이 슬롯 앞에서 0.7~1 s 버티고, 그 사이 몸통이 넘어가면 뒤따르는 앞발이 뒤처진 채 급히 따라온다.
  6566에서 가장 심하다.

### 1.4 보상 구조에서 확인한 것 (평지 전진, 초당 가중 보상, 세 모델 거의 동일)

| 항목 (가중치) | 측정값 /s | 해석 |
|---|---|---|
| `track_lin_vel_xy_exp` (+1) | +0.99 | 총 보상 +1.7/s의 대부분 |
| `flat_orientation_pitch_l2` (−1, 중력 x성분 제곱) | −0.000 ~ −0.002 | 3°에 −0.003, **8°에 −0.02, 15°에 −0.07**. 머리 들림을 막을 힘이 없다 |
| `foot_clearance` (−1, **몸통 좌표계** z −0.43 m 기준, 선형) | −0.024 | 몸을 수평으로 놓고 다시 계산하면 −0.036: **머리를 들면 뒷발 기준이 완화되어 +0.006~0.012/s 이득** |
| `feet_touchdown` (−1, 착지 순간 발 속도, 갭·계단 0.5배) | −0.001 | 착지 1회 −0.006. 추종 보상의 1 % → "쿵" 착지를 막지 못한다 |

| `feet_slipping` (−0.1) | −0.017 | — |
| 갭 전용 (`backward_nose_up` −5 등) | 0 | **갭 타일·후진 명령에서만** 켜짐. 평지에는 아무 영향 없음 |

결론: **머리 들림·급한 착지를 "사는" 보상은 없고, "막는" 보상이 사실상 없다.** 3906 → 6566에서 추가된 항목은 전부 갭
타일 전용이라 평지 보상은 세 모델이 같고, 갭에서 익힌 자세가 평지로 새어 나와도 보상은 막지 않는다.

## 3. 보상 설계 변경

원칙: (a) 자세·착지 항목은 **모든 타일, 전·후진**에 걸고, 갭·계단에서 "완화"가 아니라 "건너는 순간만 예외"로 한다.
(b) 몸통 좌표계 기준 항목을 **지면 기준**으로 바꿔 자세를 바꿔서 얻는 이득을 없앤다. (c) 벌점 크기는 추종 보상(+1/s)의
5~15 %가 되도록 잡는다(현재 1 % 이하라 무시됨). (d) 3906 코드는 건드리지 않고 새 패키지 `gd_lab.gast_gait`에 항목과
과제 설정을 둔다(§8).
