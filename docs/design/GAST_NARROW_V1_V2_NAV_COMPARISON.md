## 3. Narrow v1 → v2 변경점

| 항목 | v1 | v2 |

## 4. 기존 능력 보존 (세 학습 공통 원칙)

- 기존 지형 13열을 남긴다(갭 3열, 계단·경사·거친 지면 10종). 보상과 명령은 6566 그대로 둔다.
- 기존 동작이 변하지 않도록 새 입력은 actor 첫 층에 0으로 초기화한 열로 붙인다(additive adapter).
- v1은 3000 update 동안 후진 갭 clean 비율이 0.54 → 0.57 → 0.54로 유지됐다(끝까지 간 시도 기준).
- v2는 학습 중 10분마다 자동 감시한다.
  - 갭 단계 8.5 미만, 계단 단계 7 미만, 후진 갭 clean 0.45 미만이면 보고한다.
- 최종 선택 전에 Top-5를 6566·1748과 같은 조건으로 평가한다(라이다 켬/끔).
  - 항목: 전진 갭, 후진 갭, 계단.
  - 6566보다 2%p 넘게 떨어지는 항목이 있으면 그 모델은 쓰지 않는다.

## 6. GAST-Nav와 Narrow의 관계

- Narrow v1·v2는 GAST-Nav의 ① 좁은 통로 기능을 작게 떼어 낸 학습이다.
  - 입력: 머리 LiDAR 지도만 쓴다.
  - 명령: 기존 3칸에 여유 m만 더한다.
  - 감독기: 없다.
- GAST-Nav의 ② 시계방향 제자리 회전과 ③ 계단참 FSM, 감독기와 unknown 지도는 Narrow에 없다.
- GAST-Nav를 다시 시작할 때는 Narrow v2 결과를 참고한다: 여유 입력, 막힘 서기, 센서 결손 학습이 효과가 있었는지.
  - 특히 회전 기능은 설계부터 다시 검토하기로 했다(2026-10-26 사용자).
- onvlm2 다중 GPU 주의 (2026-10-26 수리 이후):
  - 크기 1짜리 NCCL 통신이 기본 Tree 알고리즘에서 illegal memory access를 낸다.
  - `NCCL_ALGO=Ring`이 필요하다. GAST-Nav 실행 스크립트에도 다시 시작하기 전에 넣어야 한다.
