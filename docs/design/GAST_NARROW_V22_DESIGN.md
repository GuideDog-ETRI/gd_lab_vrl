# GAST-Narrow v2.2 설계 (2026-10-27)

v2.1 Top-1 **465**에서 출발한다. 갭·계단·서기는 그대로 두고, 빠듯한 통로에서 멈추는 문제와 출구 직전 질주만 고친다.

## 1. 배경 (465, E2 seed 42 / MuJoCo narrow_only)

| 문제 정의 | 결과 | 반영 방향 |
|---|---|---|
| 갭·계단·서기 | 갭 건넘이 모든 조건에서 96% 이상, 계단 97%, 서기 99~100% | 유지 (6566 고정 증류와 갭 8열 유지) |
| 빠듯한 통로 (0.66 m, 여유 m = 0.05) | 통과율 53~94% (1111은 66~97%). 실패한 경우는 모두 넘어지지 않고 서 있었다 | 서 있으면 벌점 (`narrow_stall`), 과속 벌점은 −2에서 −1로 |
| 출구 직전 질주 | MuJoCo에서 통로 출구와 L자 두 번째 구간에 약 1초씩 1.5~2.0 m/s (명령은 0.5 / 0.35) | 통과 보상(+8)에 속도 준수 계수를 곱한다 (`narrow_success`) |

## 2. 변경 (v2.1 대비, 이것만)

| 항목 | 내용 |
|---|---|
| 통과 보상 | +8 × clamp(1 − extra / 0.5 m, 0, 1). extra는 통로 안에서 \|명령\| + 0.15 m/s를 넘은 속도를 시간으로 적분한 값(m)이다. 일찍 도착해도 더 받지 못한다 |
| `narrow_overspeed` | 가중치 −2 → −1 |
| `narrow_stall` (새로 추가) | 지나갈 수 있는 통로에서 출구 전, 명령이 0.2 m/s를 넘는데 평면 속도가 0.1 m/s보다 낮은 상태가 1.5 s를 넘으면 초당 −1 |
| 출발 | 465 (sha d39c1294…). 모든 가중치를 복사한다. PPO 최적화기는 새로 만들고, CENet 최적화기와 지형 단계는 복원한다 |
| 규모 | onvlm2 GPU 0·1·2, 4096 env × 100 step × 400 update |

지형, 6566 고정 증류, 명령, 입력, Top-5 점수는 v2.1과 같다.

## 3. 실행

```bash
scripts/gast_narrow/train_narrow_v22_3gpu.sh smoke|pilot|train
```

## 4. 판정

- 학습이 끝나면 Top-5를 6566, 1111, 465와 함께 E2로 평가한다 (`configs/gast_narrow/e2/v22_top5.yaml`).
- 목표:
  - 갭 건넘이 모든 조건에서 90% 이상이고, 셀마다 6566 대비 −2%p 이내다.
  - 빠듯한 통로 통과율이 1111 이상이고, 서기는 95% 이상이다.
  - MuJoCo `narrow_only`에서 최고 속도가 명령 + 0.3 m/s 이하다.
- 실패하면 465를 최종 모델로 둔다.
