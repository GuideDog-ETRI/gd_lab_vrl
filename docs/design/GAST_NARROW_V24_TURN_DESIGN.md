# GAST-Narrow v2.4: 좁은 공간 제자리 회전 (설계서)

2026-10-30 · B.S.Seo (ETRI) · 출발 모델: v2.3 한강 it602 (`v23_gh200_it602_top5.pt`, `69e7e065…`)

## 1. 문제 정의

| 문제 정의 | 현재 (602) | 목표 |
|---|---|---|
| 좁은 곳(지하철 통로 1.2 m, 출입문 앞, 엘리베이터)에서 방향을 바꿔야 한다 | 제자리 회전 명령(vx = vy = 0, ωz ≠ 0)은 일반 지형에서만 배웠다. 통로 타일의 명령은 항상 전진이다. 주변 벽·기둥을 보며 회전한 적이 없다 | 장애물 사이에서 몸통·다리가 닿지 않고 회전한다 |
| 회전할 공간이 부족해도 명령은 온다 | 회전이 불가능한 상황을 학습한 적이 없다 | **회전이 불가능하면 멈춘다** (통로 v2의 "막히면 서기"와 같은 방식) |
| 회전 중 몸 중심이 밀려나면 옆 사람·장애물에 닿는다 | 측정한 적 없음 | **몸 중심이 시작점에서 10 cm 안**에 머문 채 회전 |
| 회전하면 꼬리가 뒤쪽 장애물을 쓴다 | 머리 센서만 있어 몸통 뒤쪽은 거의 안 보인다(시뮬레이션은 몸통 가림이 없어 지금은 보이는 것처럼 학습됨) | 전방 Mid-360 + **후방 Mid-360(몸통 꼬리)**, 몸통 가림 반영 |
| 다리 주변 낮은 장애물(의자 앞단, 기둥 받침)은 LiDAR가 못 본다 | 하방 Depth+IR은 갭·계단 지형 입력으로만 쓰였다 | 하방 Depth+IR(GAST 4.8 s 기억)을 다리 주변 장애물 판단에 **최대한 사용** |

### 요구 사항 해석 (확인 필요 항목은 §9)

1. **회전 불가 → 멈춤:** 회전 가능 여부는 주변 자유 반경 `r_free`(시작점에서 가장 가까운 장애물까지)와 로봇 회전 반경 `R_SWEEP`(몸통·다리 점이 그리는 원, 약 0.46 m)로 정한다. `r_free ≥ R_SWEEP + m`이면 회전, 아니면 멈춤.
2. **10 cm:** 두 가지로 쓴다. (a) 측면 여유 입력 m(통로 v2부터 쓰던 입력, 0.05~0.15 m, 기본 0.10)을 회전 여유로 그대로 쓴다. (b) 회전 중 몸 중심 이동(pivot drift) ≤ 10 cm를 성공 조건으로 둔다.
3. **센서:** 전방 Mid-360(현재 머리 위치) + 후방 Mid-360(몸통 꼬리). 두 센서의 점을 지금과 같은 지도(2 × 30 × 48, 5 cm, x −0.9~1.5 m, y −0.75~0.75 m)에 합친다. **입력 형식이 그대로라 602 가중치를 그대로 이어 쓴다.** 회전에 필요한 영역(반경 0.46 + 0.15 = 0.61 m)은 이 지도 안에 들어간다.
4. **하방 Depth+IR:** 입력은 그대로(11 × 17 × 3, 8 프레임, 4.8 s). 회전하면 몸통 아래 격자가 같이 돌아 주변을 훑고, GAST 기억이 이를 쌓는다. 회전 타일에 낮은 장애물(의자 앞단 0.45 m, 기둥)을 넣어 이 입력을 쓰도록 만든다.

## 3. 회전 타일

새 종류 `turn`(KINDS 5). 타일 중앙에서 시작하고 벽·기둥·의자가 둘러싼다. 난이도(레벨 0→14)에 따라 자유 반경 `r_free`가 1.00 m → 0.45 m로 줄어든다.

| 패밀리 | 열 | 모양 | 비고 |
|---|---|---|---|
| `narrow_turn_aisle` | 2 | 양옆 의자 앞단(높이 0.45 m, 깊이 0.45 m), 앞뒤 열림. 폭 = 2 r_free | 지하철 통로 1.2 m (r_free 0.6) |
| `narrow_turn_vestibule` / `_neg` | 1 + 1 | 뒤 벽 y = −r, 옆 벽 x = ±(r + 0.15), 열린 쪽 대각선에 기둥 1개(0.04 m, 왼쪽/오른쪽) | 출입문 앞 |
| `narrow_turn_room` / `_neg` | 1 + 1 | 4면 벽, 긴 쪽 = 1.3 r (x 방향 / y 방향) | 엘리베이터 |
| `narrow_turn_tight` | 1 | 4면 벽, r_free 0.50 → 0.40 m. **모든 레벨에서 회전 불가** | "회전 불가 → 멈춤"을 레벨 0부터 학습 (v2 막다른 길과 같은 역할) |

- 모든 모양에서 타일 중앙 → 가장 가까운 장애물 거리가 정확히 r_free가 되도록 배치(검증함).
- 시작 방향: 네 축 방향 중 몸이 들어가는(여유 ≥ 5 cm) 방향을 무작위로 고르고 ±15° 잡음(여유 3 cm 이상일 때만).
- 장애물 높이: 벽 1.0 m, 의자 앞단 0.45 m, 기둥 1.0 m. 낮은 장애물은 머리 Mid-360의 아래 시야(−7°) 밖에 놓이기 쉬워 하방 Depth와 후방 센서가 필요하다.
- 지형 열: v2.3 44열 + 회전 7열 + 유지용 7열(갭 +4, 계단 정·역 +1씩, 거친 지형 +1) = 58열. 통로 아닌 타일 비율 50% 유지.
- 보통 회전 타일에서 r_free가 문턱(0.46 + m = 0.51~0.61 m) 아래로 내려가는 것은 레벨 10(3%)~13(100%)뿐이다. 그래서 `narrow_turn_tight`가 없으면 "회전 불가" 상황을 커리큘럼 후반에야 만난다. 이 열이 그 상황을 처음부터 공급한다.
- 벽 거리는 2차원으로 잰다. 몸통(바닥 위 약 0.49 m)이 의자 앞단(0.45 m) 위로 넘어갈 수 있어도 접촉으로 본다(보수적, 실제 좌석에는 사람 다리가 있음).

## 4. 명령과 에피소드

| 항목 | 값 |
|---|---|
| 시작 | 타일 중앙 ±3 cm. yaw는 네 축 방향 중 몸이 들어가는(여유 ≥ 5 cm) 방향에서 무작위로 고르고 ±15° 잡음 |
| 명령 | vx = vy = 0, ωz = 0.3~0.8 rad/s. **방향은 오른쪽 70%, 왼쪽 30%** (§9 확인). 목표 회전각 45°~180° 무작위, 도달하면 명령 0 |
| 명령 잡음 | 갱신 주기 0.05/0.1/0.2 s, 잡음 0.05 rad/s, 20%는 회전 중 1~2 s 정지 구간 |
| 회전 가능 판정 | `turnable = r_free ≥ R_SWEEP + m` (경계 ±4 cm 안은 m을 다시 뽑음, 통로 v2와 같음). R_SWEEP 0.46 m = 몸통 모서리(0.41) + 엉덩이·발 반경 여유. 학습 후 min_clearance 통계로 다시 맞춘다 |
| 성공 (회전 가능) | 목표각 도달 + 몸 중심 이동 ≤ 0.10 m + 몸통 접촉 없음 → 0.5 s 뒤 종료 |
| 성공 (회전 불가) | 회전 15° 미만, 몸 중심 이동 ≤ 0.10 m로 1.5 s 정지 |
| 실패 | 회전 불가인데 15° 넘게 돎(침범), 몸 중심 이동 > 0.20 m, 목표각에 도달했지만 도중 이동이 0.10 m를 넘음(깨끗하지 않은 회전: 즉시 종료), 몸통 접촉(기존 종료) |
| 에피소드 길이 | 20 s (기존). 최장 회전 180° / 0.3 rad/s = 10.5 s + 정지 2 s |

### 5.1 갭 머리 들림 (회전과 별개, v2.4에 같이 반영)

602도 갭을 건널 때 앞쪽이 들린다(한강 E2 평균 10.4°, p90 13°; MuJoCo에서는 더 큼). v2.3의 `gap_nose_up`(10° 초과분 −30/s)만으로는 짧은 들림(15° 초과 약 0.07 s)에 드는 비용이 작다.

| 항목 | 가중치 | 내용 |
|---|---|---|
| `gap_nose_up` | −30 /s (기존) | 문턱 10° → **5°**. 앵커는 이 항목이 표시한 표본을 계속 제외 |
| `gap_nose_peak` (새) | −6 /rad (건넘당 일회) | 갭 건넘이 인정되는 순간, 그 건넘 동안의 **최대** 들림 각 중 5° 초과분. 15° 들림이면 −1.05로 건넘 보너스(+0.5)·clean 보너스(+0.5)를 넘는다 |

충돌 검토: 건넘 보너스는 건넘 자체에, 이 벌점은 자세에만 걸리므로 "건너지 않는" 쪽으로 밀리지 않는다(건너지 않으면 갭 추락·우회 벌점이 더 큼). 물리적으로 25 cm 갭을 넘을 때 앞다리를 뻗으려면 약간의 들림은 필요할 수 있어, 0°가 아니라 5°를 문턱으로 둔다.

### 5.2 좁은 통로 후진 (회전과 별개, v2.4에 같이 반영)

602는 좁은 통로에서 후진 명령을 받으면 주저한다. v1~v2.3의 통로 타일 명령이 전진뿐이었기 때문이다(후진 기술은 갭 타일에서만 학습).

| 항목 | 값 |
|---|---|
| 대상 | 통과 가능한 corridor / door / bend 에피소드의 **25 %** (막힌 통로·막다른 길은 전진 그대로: v2 막힘 판정이 로봇 앞을 기준으로 함) |
| 시작 | 통로 앞에서 꼬리가 통로를 향하도록 180° 돌려 놓음 |
| 명령 | vx = −(그 에피소드의 전진 속도 0.35~1.20 m/s), 방향 명령은 꼬리가 경로를 향하도록(기존 편향 + 180°) |
| 센서 | 후방 Mid-360 항상 켬 |
| 보상 | 기존 그대로. 멈춤 벌점·안전 속도·과속·통과 보너스 모두 \|명령\| 기준이라 후진에도 그대로 작동 |

충돌 검토: `narrow_stall`(멈춤 −1/s)이 후진 명령에서도 작동해 "주저"를 직접 벌한다. `gap_nose_up`은 갭 타일만이라 무관. 앵커는 통로 표본을 제외하므로 6566의 전진 습관을 강요하지 않는다.

| 커리큘럼 | 회전 성공(돌기 또는 서기)을 통로 성공과 같게 처리 | 모니터 성공 정의에 추가 |
| 온라인 Top-5 | 회전 타일이 통로 통과율(P)·서기(H)를 왜곡함 | 회전 타일은 P/H에서 빼고 새 항목 R(회전 성공률)을 추가: 점수 = 0.20 P + 0.15 H + 0.10 N + 0.05 L + 0.10 W + 0.15 G + 0.10 B + 0.05 T + **0.10 R** |
| gdm 설계 원칙 (방향은 상위가 정함) | 없음: 오른쪽 전용 등 규칙은 학습하지 않고 명령 범위로만 정함 | 배포 시 gdm이 ωz ≤ 0만 내면 됨 |

## 6.1 보상 목적 대 구현 점검 (2026-10-30, 전체 55개 항목 중 회전·통로·갭에 관계된 것)

| 항목 (가중치) | 목적 | 구현 확인 | 결과 |
|---|---|---|---|
| `track_lin_vel_xy_exp` (+1) | 명령 선속도 추종 | 회전 타일 명령 0 → 게이트 열림, exp(−\|v\|²/0.09)로 제자리 유지에 보상. 막힌 구간에서는 끔 | 일치 |
| `track_ang_vel_z_exp` (+0.8) | 명령 각속도 추종 | 회전 가능 타일만. 회전 불가 타일·막힌 구간은 0 (`track_ang_vel_z_turn_gated`) | 일치 |
| `feet_cadence_overrun` (−1) | 걸음 주기 상한 | **문제 발견:** 명령이 0이 아니면 발을 0.6 s 넘게 딛고 있는 것을 벌함(최대 −2/s). 회전 불가 타일·막힌 구간에서 서 있으면 제자리걸음을 하도록 밀림 | 서야 하는 곳에서 끔 (`feet_cadence_overrun_stand_gated`) |

## 8. 평가

- **E2 회전 묶음(새로 만듦):** 자유 반경 0.50~0.90 m × m 0.05/0.10/0.15 × 오른쪽·왼쪽, 칸당 48 env. 지표: 회전 성공, 회전 불가 시 서기, 침범, 몸 중심 최대 이동, 몸통·다리 접촉.
- **E2 기존 묶음:** 갭·계단·통로가 602 대비 떨어지지 않는지 (기준 −1%p).
- **MuJoCo:** 지하철 통로(1.2 m) 회전 코스, 출입문 앞, 회전 불가 폭(0.9 m).

## 9. 확정한 결정 (2026-10-30)

1. **회전 방향:** 양방향 학습(오른쪽 70% / 왼쪽 30%), 배포는 오른쪽만 — gdm이 ωz ≤ 0만 보낸다 (10-17 사양: 시각장애인이 오른쪽 뒤).
2. **10 cm의 뜻:** 둘 다 — 회전 여유(장애물까지 회전 원 + m, 기본 10 cm)와 몸 중심 이동 한도 10 cm.
3. **후방 Mid-360 장착:** 꼬리 끝, 트렁크 중심 위 +10 cm, 뒤쪽 25° 숙임(±3°).
4. **출발 모델:** 602.
5. **한강 3906 재학습과 합치기:** v2.4 결과가 나오면 B단계 과제를 v2.3 → v2.4로 바꾼다(입력 형식 같음, `train_narrow_v24.py`는 후진 갭 체크포인트 시작도 받음).
