# GAST-Narrow v2 설계 (2026-10-26)

GAST-Narrow v1 Top-1 **1748**에서 시작한다(sha e404fb41…, 6566 → v1 3000 update 중 1748). 처음에는 6566 출발을 계획했지만, v1이 끝난 뒤 사용자 결정으로 1748 출발로 바꿨다(통과 능력을 이어받기 위해). 좁은 통로 통과에 다음을 더한다.
- 여유 m을 입력으로 받는다.
- 막힌 통로에서는 그 자리에 선다.
- 명령 범위를 넓힌다.
- 한쪽 LiDAR가 끊기거나 LiDAR가 꺼진 경우도 학습한다.

v1 코드와 동작은 바꾸지 않는다. 공통 파일은 v1 기본값을 유지하는 매개변수만 추가했다.

## 1. 사용자 결정 (2026-10-26)

| 항목 | 결정 |
|---|---|
| 출발점 | v1 1748 (모든 가중치 복사, LiDAR 인코더 포함) |
| 막혔을 때 | 그 자리에 선다 (뒤로 물러나지 않음. 길 선택은 gdm 몫) |
| 통과 기준 | B안: 로봇 폭 + 좌우 여유 m. m은 gdm이 주는 입력으로, 학습 범위는 5~15 cm, 기본 10 cm |
| 센서 | Ouster OS1-64 + Mid-360. 한쪽 센서 결손을 학습한다(②) |
| 수동 조이스틱 | 라이다를 끈다. 배포 쪽이 전부 0인 지도를 넣는다. gdm 명령이 없으면 조이스틱 명령을 쓴다 |
| 학습 | onvlm2 GPU 0·1·2 (GPU 3 금지), 합계 4096 env × 100 step × 1500 update. 일찍 끝내지 않고 끝까지 돌린다 |

## 2. 통과 / 막힘 판정

- 로봇 폭 ROBOT_WIDTH = 0.48 m. 6566이 직진할 때 쓸고 지나가는 폭(발 반경 포함)을 v1 점검 기록에서 쟀다. p5 0.47, 중앙값 0.55(자세 흔들림 포함).
- 에피소드마다 m을 U(0.05, 0.15)에서 뽑는다.
  - 폭 w ≥ 0.48 + 2m + 0.04 이면 통과 가능.
  - w ≤ 0.48 + 2m − 0.04 이면 막힘.
  - 경계 ±4 cm 안에 들면 m을 다시 뽑는다(5 cm 지도 칸의 오차를 감안).
  - 막힌 통로(dead end)는 항상 막힘이다.
- 막힘선 block_s:
  - 복도·L자 꺾임: 벽이 시작하는 곳.
  - 문: 첫 문.
  - 막힌 통로: 끝 벽 앞 0.10 m.
- 로봇 앞끝 = 경로상 위치 s + 0.45·cos(방향 오차).

## 3. 장면 (31열 × 15단계)

| 구분 | 열 | 폭 (단계 0 → 14) |
|---|---|---|
| 기존 6566 지형 | 13 | v1과 같다 |
| 직선 복도 | 4 | 1.20 → 0.50 m |
| 어긋난 문 ± | 3+3 | 1.20 → 0.50 m |
| L자 꺾임 좌/우 | 3+3 | 1.20 → 0.50 m |
| 막힌 통로 | 2 | 1.20 → 0.80 m. 끝 벽은 x 1.5 → −1.2 m로 입구 쪽으로 다가온다 |

- 시작 위치: x U(−3.0, −2.2), y ±0.40 m, 방향 ±35°.

## 4. 명령 (gdm 대용, 막혀도 계속 앞으로 민다)

- **vx:** 0.35~0.8 m/s, 에피소드 동안 고정.
- **ωz:** 0.8 m 앞 경로점을 따라가도록 계산한다(pure pursuit).
  - 방향 편향은 ±8°이고, 에피소드의 20%는 ±20°이다.
  - 최대 ±0.8 rad/s.
  - 갱신 주기는 0.05 / 0.1 / 0.2 s 중 하나이다.
  - 잡음을 더한 뒤 다시 ±0.8로 자른다.
- **vy:** 에피소드의 30%에서 ±0.2 m/s를 1~3초 켜고 1~3초 끄기를 반복한다.
- **통로 안 정지:** 통과 가능 에피소드의 20%에서 통로 안 한 지점에서 명령을 1~3초 동안 0으로 둔다.
- **통과 후:** 명령 0.

## 5. 입력

| 그룹 | 내용 |
|---|---|
| narrow_lidar | [2, 30, 48] 지도, 5 cm 칸 (v1과 같아서 1748의 LiDAR 인코더를 그대로 쓴다) |
| narrow_margin | (m − 0.10)/0.05 ∈ [−1, 1] |
| narrow_priv (critic) | v1의 6개 + [m, 막힘 여부, (막힘선 − 앞끝)/2] |

- **LiDAR 결손:**
  - 10%는 Ouster만, 10%는 Mid-360만 켠다.
  - 10%는 0~8초 사이 임의 시점에 한 센서를 잃는다.
  - 기존 지형 에피소드의 10%는 두 센서를 모두 끈다(지도 전부 0, 조이스틱 모드).
- **actor 첫 층:** 251 → 252 (m 1), 새 열은 0으로 시작한다.
- **critic 첫 층:** 304 → 307 (특권 3), 새 열은 0으로 시작한다. 시작 시 정책은 1748과 같다.

## 6. 보상·종료 (좁은 통로 타일만)

| 항 | 가중치 | 내용 |
|---|---|---|
| narrow_success | +8 | 통과 가능 에피소드에서 출구 통과 1회 |
| narrow_hold | +4 | 막힘 에피소드에서 구역 안에 1.5초 정지(0.10 m/s 미만) 1회 |
| narrow_stand | +0.5 /s | 막힘 구역(막힘선 1.2 m 앞부터)에서 exp(−(속도/0.1)²) |
| narrow_breach | −4 | 앞끝이 막힘선 +2 cm를 넘으면 1회 부여하고 종료 |
| narrow_wall_proximity | −1 /s | 벽까지 (m − 2 cm) 이내로 들어간 비율의 합 |
| narrow_centering | +0.3 /s | v1과 같다 |
| 추종 보상 | — | 막힘 구역 안에서는 끈다 (명령이 계속 밀어도 서 있는 쪽이 손해가 아니게) |

- **커리큘럼:** 통과 또는 서기에 성공하고 벽 접촉이 0.2초 미만이면 단계를 올린다. 실패하거나 침범하면 내린다.

## 7. Top-5 (매 update, 100부터)

- **점수:** 0.25 P + 0.15 H + 0.10 N + 0.05 L + 0.10 W + 0.15 G + 0.15 B + 0.05 T
  - P: 통과율
  - H: 막힘 서기율
  - N: 여유가 10 cm 미만인 빠듯한 통과율
  - L: L자 통과율
  - W, G, B, T: v1과 같다
- **조건:** 갭 평균 단계 ≥ 9, 계단 종료율 ≤ 6%, 나머지는 v1과 같다 (`configs/gast_narrow/online_top5_v2.json`, 학습 중 바꿀 수 있다).
- **기존 능력 감시:** 10분마다 갭 단계 8.5, 계단 단계 7, 후진 갭 clean 0.45 아래로 떨어지는지 확인한다. 최종 선택은 6566·1748과 갭(전진·후진)·계단을 비교 평가해 2%p 넘게 떨어지면 제외한다.

## 8. 실행과 onvlm2 주의

```bash
scripts/gast_narrow/train_narrow_v2_3gpu.sh smoke   # 192 env x 16 x 5
scripts/gast_narrow/train_narrow_v2_3gpu.sh pilot   # 4096 x 100 x 50, 약 21 s/update
scripts/gast_narrow/train_narrow_v2_3gpu.sh train   # 4096 x 100 x 1500, 약 20.9 s/update, 약 8.7 h
```

- 2026-10-26 수리 후 onvlm2에서는 크기 1짜리 NCCL 통신이 기본 Tree 알고리즘에서 illegal memory access를 낸다.
  - 4 MB 통신과 `NCCL_ALGO=Ring`은 정상이다.
  - 그래서 실행 스크립트 기본값을 Ring으로 두었다. 소켓 전송(P2P/SHM 끔, lo)은 이전과 같다.
- 확인 결과:
  - 로컬과 onvlm2의 1 GPU smoke, onvlm2의 3 GPU smoke와 pilot을 통과했다.
  - 새 열이 0인 상태로 돌리면 막힘 에피소드는 전부 침범한다. 학습할 대상이다.
  - 정지 자세로 돌리면 서기 판정이 나오고 침범은 0건이다.

## 9. 위험

- 서기를 배우면서 빠듯한 통로 통과율이 v1보다 떨어질 수 있다. 1748을 기준으로 비교한다.
- 5 cm 지도 칸으로 ±4 cm 경계를 구분해야 해서, 경계 근처 판단은 거칠 수 있다.
- ROBOT_WIDTH 0.48은 6566 기준값이다. 학습 후 자세가 바뀌면 다시 잰다.
- 좁은 통로에서 라이다를 끈 상태는 학습하지 않는다(사람 책임). 라이다를 끄면 배포 쪽이 0 지도를 넣어야 한다. 마지막 지도를 그대로 두면 안 된다.
