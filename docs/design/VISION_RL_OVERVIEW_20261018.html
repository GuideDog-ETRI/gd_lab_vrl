1부. 목적과 전체 구조

1.1 목적

RBQ10 안내견 로봇이 시각장애인을 하네스로 이끌며 지하철 승강장 갭(2–26 cm, 단차 0–16 cm), 계단(5–25 cm), 경사·거친 바닥을 넘도록 한다. 블라인드 정책은 갭 앞에서 발이 빠지고 계단 앞에서 걸려 넘어진다 — 몸 앞·아래 지형을 보는 정책이 필요하다. 추가 요구:

  • 페이로드 0/6 kg(실사양 5 kg: 머리 2 + 중앙 2.5 + 후방 0.5)에서 같은 성능.
  • 핸들 외력: 계단에서 사람이 하네스를 당기거나 미는 힘(오르막 ≤200 N, 내리막 ≤150 N)을 견딘다.
  • 실제 센서: 로봇 하부 RealSense D4xx 4대(depth + IR). LiDAR는 내년 탑재 예정이며, 지금 구조는 LiDAR 경로도 같은 지도 형식으로 받는다.
  • 실시간: 정책 100 Hz, 지형 캡처 10 Hz, 로봇 CPU에서 ONNX 추론.

1.2 방법의 변천 — 왜 "교사 직결"인가

CVTT (09-23~10-01)렌더 카메라 가시성 교사 + 카메라 학생(RVLD/GAVD)학생이 갭·계단 미통과. 렌더 비용 큼

3부. 지형처리기

"지형처리기"는 센서 측정을 2.2절의 11×17 프레임으로 바꾸는 부분이다. 학습 쪽(Isaac, GPU 텐서)과 배포 쪽(매퍼, CPU)이 같은 프레임 의미를 만들도록 설계했다.

3.1 학습 쪽: RaycastIrTerrain (src/gd_lab/gast/rayir.py)

GT 높이 스캔 히트 (11×17)
  → 가시성: 장착 카메라 4대(camera contract vendor_new)에서 각 히트점까지 레이캐스트, 다리 캡슐 가림 → 보이는 셀만
  → 높이 노이즈 N(0, 1 cm) + 에피소드 bias N(0, 1.5 cm)
  → dropout 3%
  → blackout: 스텝당 시작확률 0.001, 길이 50–300 step, 에피소드 전체 5% (IR 포함 전부 0)
  → 무효 셀 h=0 / valid=0 / IR=0
  → 카메라 계약 시계에 맞춰 캡처, 다음 캡처까지 hold (height·mask·IR이 같은 캡처 pose 공유)

IR 프록시(셀 단위, gap/지형 라벨 미사용): I = clip(a + g·ρ(x,y)·max(0, n·l)·(r0/r)^0.5 + N(0,σ), 0, 1), a 0.05 · gain 0.57 · r0 0.6 m · σ 0.03 · IR dropout 3%. n = GT 표면 법선, l·r = 그 셀을 보는 가장 가까운 카메라 방향·거리, ρ = 월드 고정 재질장(어두운 패치 약 10%, 밝은 패치 약 15%, 저반사 띠), g = 에피소드 노출. noen rosbag 실측 IR(평균 0.34, p10 0.22, p90 0.46, 포화 없음, 거리 감쇠 (r0/r)^0.5)에 맞췄다.

4부. Actor-Critic·PPO 학습

4.1 네트워크 (GastRayIrActorCritic)

TemporalTerrainEncoder (src/gd_lab/gast/temporal.py), 입력 8 × (3·187 + 1)
  프레임별 CNN : Conv(3→8,3×3) ELU → Conv(8→16,3×3) ELU → AdaptiveAvgPool(5×8) → FC 640→64 ELU
  + age 임베딩 : Linear(2→64) of (age/5, valid 평균)
  → MultiheadAttention(64, 4 heads)  [math SDPA 강제]  → LayerNorm(residual)
  → GRU(64) → FC 64→32 + Tanh  = terrain latent 32   (valid 셀 0개면 0)
보조 decoder : latent 32 → FC 128 → 187×6  (깨끗한 높이·valid·semantic gap·gap-known 재구성)
CENet        : 블라인드와 동일 (enc 128-64, dec 64-128, latent 16, β 1.0, AdaBoot) — 블라인드 문서 1.2–1.3절
actor        : 97 → 512 → 256 → 128 → 12 (ELU),  critic: 특권 obs → 512-256-128 → 1

terrain latent는 detach하지 않는다 — PPO 경사가 encoder를 직접 학습시킨다. 보조 재구성 손실(height smooth-L1 + valid/gap BCE, gap 셀 가중 ×5)은 업데이트마다 2048 샘플, 계수 0.1, PPO와 같은 Adam으로 한 번 더 step한다.

4.5 PPO와 수치 안정성 (GastPPO)

horizon 100, 5 epoch × 4 minibatch, lr 1e-3 fixed(하한 3e-5), γ 0.99, λ 0.95, clip 0.2, entropy 0.01, desired_kl 0.01, max_grad_norm 1.0, 대칭 데이터 증강(mirror_gast, mirror loss 0). 3906 규모: 1024 env × 5000 iter, 1 GPU(90.111). DDP는 --distributed --total_envs N(rank별 divmod 분할).

안정성 교훈 (코드에 반영됨)
  • fused SDPA backward가 inf gradient의 원인(GAST v2.1 8016/8148 정지) → GAST_MATH_SDPA=1로 math kernel 강제. 대칭 증강으로 배치가 2배가 되면 CUDA attention grid 한계를 넘으므로 encoder를 8192 chunk + checkpoint로 실행.
  • 비유한값 가드: rollout·상태·optimizer에 NaN/inf → 업데이트 skip 후 마지막 정상 스냅샷 복원. 보조 손실은 fp64 norm 검사 후 정상일 때만 rank 평균.
  • CENet 이상치: 타깃(velocity/recon/history) clamp로 방어. gradient clipping은 측정상 효과 없음.

4.6 모델 선택 — online Top-5 (rl/online_top5.py)

학습 rollout 통계로 후보를 뽑는다(held-out 평가 아님). 조건: iter ≥500, 간격 ≥500, 지형 평균 레벨 ≥9, platform_gap 평균 레벨 ≥8, base contact·gap 종료·계단 종료율 ≤9%, 현 Top-1 대비 gap 성공·contact 회귀 ≤1.0 pp. 점수는 (family, level) 그룹별 가중 macro 평균. 기준 파일: configs/gast/online_top5_rayir.json(hot reload). 최종 선택은 E1과 MuJoCo로 한다(5부) — online 점수 1위가 MuJoCo에서 무너진 사례가 있다(A3906 5737: 1/5).

4.7 파인튠: aug149 매퍼 오차 증강 (브랜치 aug149-mapper-aug)

목적: Isaac의 깨끗한 Ray 입력과 실제 매퍼(3.2절) 출력 차이를 actor가 견디게 한다. actor 입력에만 적용, critic은 clean.

  • deepest-of-5 footprint + 에피소드 고정 pit 확장(최종 반경 ≤10 cm), gap 타일에서만 support-0.7 m pit 깊이.
  • 군집형 unknown: valid의 5–15%를 blob + 맵 경계 띠로 제거. IR은 유지(무효 셀 0).
  • 25% clean 에피소드, 국소 500 업데이트 ramp, 별도 RNG(기존 노이즈 난수열 불변).
  • strict resume(--resume_rayir149): SHA·task 일치 검사, PPO·CENet optimizer와 family 레벨 복원, 조용한 fallback 없음. 주의: --max_iterations는 추가분.
  • 규모 +2000 iter: A3906(90.111), A2769·C2769 대조(onvlm2).

4.8 카메라 학생 (보류 — 참고)

Ray+IR 이전에는 교사 latent를 카메라 학생으로 증류했다. 최종 학생 GAST-S/B3: 4×80×45 depth+IR → 공유 CNN → 보정된 격자 cross-attention(187셀) → 시간 attention·age 임베딩·셀별 GRU(pose warp) → latent 32. 손실 = 고정 actor를 통한 행동 MSE + 0.5·기하(가시 셀 높이·가시성 BCE) + 0.1·품질 BCE, DAgger식 혼합(학생 구동 확률 ramp). 최고 B3 s42 58084: E1 72.6%. 교사 직결(카메라+필터 96.2%)보다 낮아 배포 경로에서 제외했다. 코드: src/gd_lab/gast/{student,distillation,b3_objective}.py.

6.4 현재 한계

  • sidecar의 IR은 코스 GT 기하로 계산한다(실제 IR 영상 아님). depth 잡음에 stereo fill-in 패치는 없다.
  • 계약은 history 초기값을 zeros로, launcher는 RBQ_VRL_HISTORY_INIT=repeat_first를 쓴다 — 하나로 맞춰야 한다.
  • force4_classify의 갭 창과 코스 XML 표식이 약간 다르다 — 정리 필요.
