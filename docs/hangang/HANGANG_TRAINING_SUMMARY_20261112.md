# KISTI 한강 GH200 학습 수행 내역 (2026-10-28 ~ 11-07)

RBQ10 안내견 로봇 시각 보행 정책(GD_VRL)을 KISTI 한강 슈퍼컴퓨터에서 학습한 내역이다. 단계마다 해결하려던 문제, 사용한 자원과 환경, 사용 시간, 결과와 다음 단계 반영을 정리했다.

## 요약

| 항목 | 값 |
|---|---|
| 기간 | 2026-10-28 ~ 11-07 (11일) |
| 최대 규모 | 236노드 (GH200 944장, 환경 193만 개), 초당 252만 스텝 |
| 주력 규모 | 16노드 (GH200 64장, 환경 131,072개) |
| 총 사용량 | 약 6,300 노드·시간 = 약 25,300 GPU·시간 = 약 758만 SRU-초 |
| 최종 산출 | 배포 모델 it861 (좁은 통로 + 승강장 갭 + 계단). 갭 98.3 %, 계단 95.7 %, 통로 95.8 %, 막힌 통로 서기 100 % / 침범 0 |

## 1. 공통 환경

| 항목 | 내용 |
|---|---|
| 시스템 | KISTI 한강 natStr 파티션, 노드당 NVIDIA GH200 4장 (계산 노드 GPU 메모리 96 GB) |
| 소프트웨어 | 자체 빌드 aarch64 컨테이너(Apptainer): CUDA 12.8, PyTorch 2.7, Isaac Sim 5.1, Isaac Lab 2.3.1, rsl-rl 3.0.1 |
| 병렬 방식 | PyTorch DDP(torchrun), 노드당 1 task × GPU 4. 노드 간 통신 aws-ofi-nccl 1.20.0 + libfabric(cxi), `NCCL_PROTO=^LL128` |
| 학습 방식 | PPO. 갱신 1회 = 로봇마다 100스텝 수집 + 5 epoch × 4 미니배치. 학습률 고정(정책 1e-4, 지형·LiDAR 3e-4). 매 갱신 온라인 Top-5 저장 |
| 운영 조건 | 작업당 24시간, 사용자당 동시 작업 5개. 원격 명령 시간 제한, 작업 종료 15분 전 저장 |

## 5. 산정 기준과 참고

- 10/30 이후 사용 시간은 각 작업 로그(slurm)의 시작·종료 시각으로 계산한 실측값이다.
- 10/28–30 묶음은 규모 시험, 236노드 학습, 8노드 PPO 비교를 함께 집계한 값이다. 작업별 내역은 한강 `sacct`로 확인할 수 있다.
- 평가(E2)는 고정 조건에서 결정론적 정책으로 칸별 성공률을 재는 시험이다. 최종 모델 선정 E2는 A6000 서버에서 수행했다.
