# RBQ10 policy lineage, 2026-10-16, updated 2026-10-18 around the original 3906 (including failed and stopped runs)

This table was collected read-only from the training records on all three hosts: `params/`, manifests, package READMEs, console logs and tfevents host names.
The graph view is `rbq10_lineage.html`.

**Notation**
- `env` is the total number of environments; for DDP it is summed over ranks.
- `a→b` is the start and end iteration. For students it counts captures.
- `nG` is the number of GPUs.
- Hosts:
  - **local** = the 5090 machine (user-Z890)
  - **onvlm2** = the multi-GPU server
  - **90.111** = the second 5090 server
- `?` means the record does not exist.

**Gains**
- ARM4: 100 Hz, Kp hip 123.39 / knee 127.77, Kd 2.4.
- ARM1: 50 Hz, default gains.
- ARM2: 100 Hz, default gains.
- ARM3: 50 Hz, same Kp as ARM4.
