읽을 때 주의할 점

  • 두 개의 블라인드 뿌리. b1_18 ONNX 계열(17206 → 21068 → GAST 2000·26123 → 2769·2836)과 DWB-38000 계열(BIVT 2-A·Render·Ray 4500·Enhanced, BAVRL, 3906)은 서로 다른 블라인드에서 출발함.
  • b1_18은 50 Hz ONNX(policy_dt 0.02, Kd 2.5)인데 17206 계열은 100 Hz ARM4 이득으로 학습함. b1_18 자체의 학습 기록은 남아 있지 않음.
  • 같은 이름 다른 모델. DWB-38000(c6cfe178)은 onvlm2 ARM4 블라인드 런의 model_38000이고(SHA로 확인), 90.111의 ARM2 model_38000(c1d451f4)과 다름.
  • GAST v2.1은 21068에서 출발했고, model_2000은 그 런 안의 체크포인트. 26123은 같은 런을 8400부터 이어 30000까지 학습한 결과.
  • Clean 런은 34947에서 정지. 21068은 초반 Top-1(채택), 31625는 마지막 Top-1(뒷발 습관)으로 v2 가지의 출발점.
  • 기록 공백. ARM3 중단 사유, Enhanced Ray의 GPU 개수, 초기 RVLD 학생의 서버는 기록이 없어 표시하지 않음.
