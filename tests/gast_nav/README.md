# UPDATE159 C2 CPU fixtures

Run on 90.111, without GPU/simulator/training:

```bash
cd /home/onvlm/gd_project/transfer_collab_20261009/update159_gast_nav
./tests/gast_nav/run_cpu.sh
```

The runner uses the existing venv inside the existing SIF **without `--nv`**, sets
`CUDA_VISIBLE_DEVICES=''`, mounts the original project read-only, and keeps tmp,
pytest outputs and Apptainer cache under this staging folder. No installation or
git operation is performed. `conftest.py` adds this staging `gd_lab` overlay to
the local regular package's search path; after copying the owned gast_nav files
into the destination repository this overlay shim is not required.

`golden/obs1_*.json` was generated by the independent stdlib-only scalar reference
`make_golden.py`. Tests load committed JSON rather than regenerate it. The cases
contain rays/point cloud, sample pose/support, complete base64 wire bytes and
sparse decoded expectations; scalar clearance is computed independently of the
torch implementation. Do not regenerate golden to hide a failing code change.

All poses are **(odom x,y,z,yaw)**, units metres/radians, timestamps monotonic ms.
All raw rays and fitted normals must already be transformed to the capture's
body-yaw frame. Ray distances are physical metres; directions are normalized by
the implementation. A valid no-return distance is +inf. Self-hit only refers to
the supplied static return; a closer analytic dynamic hit wins.

Primary integration path:

1. `make_seed_mask(...)` combines measured contacts and valid body-near terrain.
2. `grow_support(..., segment_type=..., current_support_height=...)` returns
   support reference metres, its byte encoding, and a separate walkable-surface
   mask. The route hint is from gdm, not a privileged terrain label. FLAT raised
   surfaces use the current measured floor reference for obstacle classification;
   they are not accepted as support. Unknown/gaps stay unknown.
3. `ObstacleMap(N).update(...)` yields an immutable-by-contract capture frame;
   `history` is newest first and limited to three captures. Do not mutate its
   tensors. `reset(env_ids)` increases per-env epoch and restarts seq at zero.
4. `build_near(...)` consumes raw rays and an independent observed fine support
   grid of shape `[N,45,57]` (ROI+0.5m), never wide occupancy upsampling.
5. `encode_obs1(wide, near, env_index=...)` / `decode_obs1(bytes)` are local-IPC
   serialization. `OBS1Receiver.receive(...,now_ms=...)` also enforces monotonic
   epochs/seq. Do not feed already age-adjusted `.valid_at()` frames into raw
   `network_inputs`: that function applies elapsed time itself exactly once.
6. `network_inputs(frames,near,current_pose,now_ms)` -> `[N,27,43,49]` and
   `[N,3,25,37]`. Or single-env `packed_network_inputs(packets,...)`.

Wire v1 is 9,426 bytes: 144-byte fixed header, 9,278-byte payload, CRC32 4 bytes.
See `packets.py` for field order, exact format, metadata, and array padding.
The initial request's 6.7kB estimate predates support heights and fine ages.

No Isaac/MuJoCo sensor acquisition, CUDA throughput, actual IPC transport,
ONNX/C++ runtime, or full policy integration is exercised by these fixtures.
